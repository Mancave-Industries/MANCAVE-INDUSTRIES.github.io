How to cut these in Cricut Design Space
  1. In Design Space choose Upload → Upload image, pick one layer SVG, and insert it. Check the size panel shows the sheet size listed in the report. Don't resize it.
  2. Each file is a single cut. Every layer has the same sheet outline, the same four corner crosses, and small notches along the bottom showing the layer number.
  3. Cut each layer from stencil film, vinyl or card. Weed out the cut pieces: the holes are where the paint goes.
  4. Spray layer 1 first. Line up the next sheet using the corner crosses (mark them through with a pencil on the first pass) and work up to the last layer.
